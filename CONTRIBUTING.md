# Contributing and Reporting Issues

[日本語 / Japanese](CONTRIBUTING.ja.md)

Please use GitHub Issues (after the repository is published) to report **reproducible bugs in the companion materials**. This is not a support channel for private deployments, consulting, or investigations involving sensitive organizational data.

For a useful report, include the materials version, operating system, Python version, commands run, expected and actual behavior, and the smallest reproducible example you can share. You do not need to share book content or proof of purchase.

**Never attach** API keys, authentication tokens, personal information, proprietary source code, customer data, or nonpublic logs. Acceptance of pull requests, individual responses, and response times are not guaranteed.

The fact that the existing test suite passes is not sufficient evidence that every possible state transition is handled. If you find a transition the tests miss, describe it explicitly along with its expected control boundary.
